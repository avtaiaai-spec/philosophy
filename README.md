# Эго

Личная учебная студия философии на русском языке: чтение, тесты, эссе, устные выступления, книги и заметки. Адаптивный светлый интерфейс с бирюзовыми, мятными и янтарными акцентами.

## Запуск

Требуется Node.js 20 или новее. Устанавливать пакеты не нужно.

```sh
cd /workspace/philosophy
npm start
```

Сервер слушает порт 3000 на всех интерфейсах. Можно задать другой порт: `PORT=8080 npm start`. Для разработки также есть `npm run dev`. Сборка не требуется: сервер отдаёт ES-модули напрямую.

Каждая облачная задача уже изолирована: используйте существующий checkout, дополнительный Git worktree не нужен.

## Что реализовано

- Полные вводные модули «Что такое философия», «Стоицизм», «Экзистенциализм»: по пять разделов, понятия, мыслители, резюме и источники.
- По шесть вопросов теста с объяснениями, сохранение результата и повтор ошибок.
- Открытые ответы, личные заметки с тегами, три темы эссе для каждого модуля, автосохранение и счётчик слов.
- По шесть вопросов для устной практики: выбор всех, изученных или конкретной темы; случайный вопрос; пять минут подготовки; ранний старт; отдельный таймер выступления; тезисы и самооценка.
- Запись голоса через MediaRecorder, сохранение в IndexedDB, прослушивание, скачивание и удаление. Отказ в разрешении не блокирует остальные функции.
- Семь художественных произведений, связь с темой, сложность, вопросы после чтения и три статуса списка чтения. Философские первоисточники выделены отдельно.
- Поиск записей по тексту, теме и тегам, фильтр по типу и экспорт личных текстов в Markdown.
- Закладки тем, прогресс, последнее занятие и будущие модули с отметкой «Скоро».

## Архитектура и данные

- `src/data.js` — авторские вводные пересказы, тесты и книжные рекомендации. Это не дословные цитаты первоисточников. Для дальнейшего изучения указаны конкретные работы.
- `src/app.js` — навигация через hash URL, интерфейс, автосохранение, таймеры и браузерные аудиозаписи.
- `src/style.css` — адаптивный интерфейс; нижняя навигация на телефонах.
- `server.mjs` — статический HTTP-сервер без сторонних зависимостей.

Тексты и прогресс находятся в `localStorage` под ключом `ego:v1`. Аудио хранится в IndexedDB `ego-audio`. Данные привязаны к браузеру, профилю и origin (включая порт). Очистка данных сайта удаляет записи. Синхронизации между устройствами, аккаунтов и сервера пользовательских данных нет. Тексты можно экспортировать, аудио нужно скачивать отдельно. Объекты аудио текущего несохранённого выступления находятся в памяти до нажатия «Сохранить практику» или завершения выступления. Перезагрузка страницы до сохранения аудио может его потерять.

Приложение не использует внешние шрифты, CDN, аналитику или удалённые изображения. Во время работы сторонние запросы не нужны. Автоматический анализ ИИ и расшифровка не подключены: вместо них есть явно обозначенные критерии самооценки. Их подключение в будущем потребует отдельного серверного API и согласия на передачу текста или аудио.

Для доступа к микрофону нужен безопасный контекст: HTTPS или localhost. В Chromium поддерживается WebM, в других браузерах формат выбирается MediaRecorder. При недоступности микрофона остаются таймер, заметки и самооценка. Физический микрофон пользователя и специфические особенности Safari необходимо проверять на целевом устройстве.

## Проверки

```sh
npm run check
# В отдельном терминале при работающем сервере:
python tests/smoke.py
```

Браузерный тест требует установленного Python Playwright и Chromium. В этой облачной среде они доступны. Настройки: `EGO_URL`, `CHROMIUM_PATH`, `EGO_ARTIFACTS` (по умолчанию `/tmp/ego-tests`). Эти инструменты нужны только для проверок, не для приложения.

Проверяются чтение, сохранение заметок/ответов/эссе после перезагрузки, закладки, прогресс, объяснения теста и повтор ошибок, библиотека, поиск и экспорт, оба таймера с управляемыми часами, запись с виртуальным микрофоном, IndexedDB, скачивание/удаление аудио, отказ в разрешении микрофона и отсутствие горизонтального переполнения девяти экранов на ширине 390 px. Скриншоты сохраняются вне репозитория.

## Публикация на GitHub Pages

Приложение совместимо с адресом проекта `/philosophy/`: пути к ресурсам относительные, навигация использует hash URL. Сервер Node.js для опубликованного сайта не нужен.

В репозитории есть workflow `.github/workflows/pages.yml` — **«Опубликовать Эго»**. Он публикует только `index.html` и `src`, без тестов, сервера и служебных файлов.

Однократная настройка:

1. Откройте репозиторий `avtaiaai-spec/philosophy` на GitHub.
2. Перейдите в **Settings → Pages**.
3. В **Build and deployment → Source** выберите **GitHub Actions**. В этом режиме ветка и папка не выбираются; отдельная кнопка Save может отсутствовать.
4. Перейдите в **Actions → Опубликовать Эго → Run workflow**, выберите ветку **main** и нажмите **Run workflow**.
5. Дождитесь зелёной галочки у задачи публикации. Адрес будет указан в результате запуска и в **Settings → Pages**: `https://avtaiaai-spec.github.io/philosophy/`.

Далее изменения в `main` запускают публикацию автоматически. Ручной запуск также остаётся доступен. Для успешной публикации должны быть разрешены GitHub Actions и Pages для репозитория. Если запуск завершается ошибкой, откройте красный шаг, чтобы увидеть точную причину.

Сайт не содержит личных записей пользователей: они сохраняются в браузере. Записи с локального адреса автоматически не переносятся на GitHub Pages, поскольку это другой origin. Экспортируйте важные тексты заранее. HTTPS GitHub Pages подходит для запроса доступа к микрофону.
